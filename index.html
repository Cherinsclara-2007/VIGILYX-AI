        Smart Autonomous Video Surveillance System

        An AI-based system that watches a camera feed, detects people with a YOLO model, and raises an alert when someone enters a restricted zone. Events and clips are logged so they can be reviewed later.

        How it works

        1. CaptureOpenCV reads frames from the camera.
        2. DetectYOLO finds people in each frame.
        3. Check zoneA person inside the restricted area triggers an alert.
        4. RecordThe event and a clip are saved for review.

        This interface is a frontend prototype. It does not run detection or record video until connected to the Python backend.
